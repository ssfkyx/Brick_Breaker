# bb_v2

Reserved for a future rewrite of the game — for example a multi-file package
split out of the M1–M11 modules of `bb_v1/brick_breaker.py`.

The directory is intentionally empty apart from this file: v1 remains the
supported, tested implementation, and a rewrite should start only when its design
and test plan are agreed on. Read [`CONTRIBUTING.md`](../CONTRIBUTING.md) before
contributing.
